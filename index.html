다섯 가지 실습은 모두 같은 모양이었습니다. 이 흐름을 이해하면 새 업무에도 같은 방식으로 AI를 붙일 수 있습니다.

1 원본읽기 전용 자료xlsx, csv, pdf, 영수증 이미지. 수정하지 않음
2 기준MD · 스킬규정, 판정 기준, 디자인 토큰, 보고 요청서

6 공유게시·전달담당자 확인 후 Artifact, GitHub Pages, 파일

AI의 역할은 무엇이고, 무엇이 아닌가

AI는 흐름을 설계하고 Python을 작성하고 실행하고 결과를 해석합니다. 하지만 최종 숫자를 직접 계산해서 적지 않습니다. 교재 AI-01도 정확한 수치 판단을 AI가 어려워하는 일로 꼽고, 계산 도구와 원본 데이터로 다시 확인하라고 합니다. 최종 승인은 언제나 담당자가 합니다(SAFE-02).

4 · 개인 프로젝트 A

월말 예산 집행 보고: 과제 요구와 구현

교재: A · 월말 예산 집행 보고

가상 기업 다온커머스의 예산 담당자 입장에서 CFO 회의용 단일 HTML 보고 화면을 만드는 과제입니다. 교재는 화면 구성을 직접 설계하라고 하고, 9월 보고 뒤에 10월 자료로 다시 실행해 재사용성을 확인하게 합니다.

이 과제의 핵심 함정: 네 가지 서로 다른 시각

교재가 강조하는 점은 전표의 회계월, 실제 전기 시각, 발주의 귀속월, 결재의 결정 시각이 서로 다른 정보라는 것입니다. 추출본에는 기준 시각 이후의 기록도 들어 있습니다.

요구사항별 구현 내용

교재·요청서의 요구구현한 방법
기준 시각 당시 상태로 계산전표는 전기 시각 ≤ 기준만 실적. 결재는 발주별로 기준 이전 마지막 기록을 상태로 사용
부분 청구 발주는 미처리 잔액만현재 발주액(최초+변경) − 같은 발주·행에 연결된 기준 이전 전표
한 발주의 여러 행·귀속월보고월 귀속 행만 반영. 다음 달 귀속분은 제외 목록에 표시. 전월 발주의 당월 귀속 행도 포함
결재 대기 승인은 별도 시나리오확정 전망과 분리한 "승인 시 차이" 열과 순위
예산 누락·발주 연결 오류·결재 근거 누락확인 목록에 금액과 원본 파일·행 번호
초과액 원본을 바로 찾기행을 펼치면 예산·전표·발주·결재 원본 위치
한 문단 요약 + 상세, 단일 HTMLPython이 계산한 JSON을 HTML 템플릿에 넣어 한 파일로 출력
원본 추출 파일 수정 금지읽기만 함. 작업 전후 수정 시각으로 확인
10월 재실행: 9월 숫자·날짜가 남지 않을 것보고월·기준 시각·문서번호를 자료에서 읽도록 바꾸고, 9월을 다시 돌려 이전 결과와 같은지 확인
9월 보고와 섞어 계산하지 않음10월 요청서의 전월 비교는 10월 폴더 안 9월 자료를 9/30 기준으로 따로 계산해 비교 표에만 사용

이 과제에서 배운 것

처음 만든 9월 코드에는 PO 번호, "9월" 문구, 특정 부서 판정 문장이 직접 들어 있었습니다. 다음 달 자료를 넣어 보기 전에는 보이지 않는 문제입니다. 교재가 10월 자료를 따로 준 이유가 이것입니다. 두 번째 데이터로 돌려 보는 것이 가장 확실한 재사용성 검사입니다.

Python은 AI가 만든 계산기이자 작업 도구입니다. 한 번 만들어 두면 다음 달에도 같은 규칙으로 다시 돌릴 수 있습니다.

무엇에 쓰나

  • 엑셀·CSV 읽기 (openpyxl, pandas, csv)

  • 데이터 품질 검사 (PASS·WARN·FAIL)

6 · 형식

JSON: 무엇을, 어디서, 어떻게

JSON은 프로그램끼리 주고받는 표준 서식의 데이터 묶음입니다. 사람도 읽을 수 있지만 주 독자는 프로그램입니다. Python의 dict·list와 모양이 거의 같아 변환이 쉽습니다.

모양

기본 문법

{
  "year": 2021,
  "annual": { "revenue": 39269602093 },
  "monthly": [
    { "month": "2021-01", "revenue": 2632386160 }
  ]
}

{ }는 이름-값 묶음, [ ]는 목록입니다. 문자열은 큰따옴표만 씁니다. 주석과 마지막 쉼표는 쓸 수 없습니다. 교재 AI-06에도 이 두 가지 때문에 설정 파일 오류가 나는 사례가 있습니다.

오늘 쓰인 곳

네 가지 역할

  • 저장된 중간 결과: data/2021.json. 분개장 7만 행을 미리 집계해 두어서, 엑셀이 바뀌지 않았으면 다시 집계하지 않습니다.
  • AI 판단을 보고서로 전달: 전표 검토에서 AI가 판정을 JSON으로 쓰면 build_report.py가 PDF로 만듭니다.
  • 실행 결과 신호: 월마감 스크립트가 "status": "PASS"일 때만 파일을 전달합니다.
  • 설정 파일: .claude/launch.json, .claude/settings.json (권한 허용·거부)

8 · 설정

.claude 설정 폴더: 어디에 적으면 어디까지 적용되나

교재: AI-06 · 설정 폴더와 전역·지역 설정

같은 설명을 대화마다 반복하지 않으려고 규칙을 파일로 적습니다. 어느 파일에 적는지가 곧 적용 범위입니다.

위치적용 범위공유오늘의 예
조직 관리 설정회사 PC 전체, 가장 우선개인이 바꿀 수 없음-
.claude/settings.local.json이 프로젝트, 내 PC만저장소에 올리지 않음-
.claude/settings.json, CLAUDE.md, .mcp.json이 프로젝트, 모든 팀원저장소에 함께 저장.claude/launch.json(미리보기 서버)
.claude/skills/이름/SKILL.md이 프로젝트의 반복 절차저장소에 함께 저장voucher-review, monthly-close-brief
~/.claude/settings.json, ~/.claude/CLAUDE.md내 PC의 모든 프로젝트, 가장 낮은 우선순위개인-
~/.claude/projects/…/memory/도구가 스스로 적는 메모내 PC만가상환경 위치, 빌드 위치

규칙 문서는 안내일 뿐, 차단 장치가 아니다

CLAUDE.md는 AI가 참고하는 안내입니다. 반드시 막아야 하는 동작(예: .env 읽기, 파일 삭제)은 settings.json의 permissions.deny나 훅으로 막습니다.

대화 기록은 평문으로 남는다

AI가 읽은 파일 내용과 명령 결과가 ~/.claude 아래에 기록됩니다. 실습에 실제 회사 자료를 쓰지 않는 이유입니다. 인증정보와 실제 자료 경로는 공유 설정에 넣지 않습니다.

// .claude/settings.json 예시: 조회는 허용, 위험한 동작은 거부 (JSON이라 실제 파일에는 이런 주석을 쓸 수 없음)
{
  "permissions": {
    "allow": ["mcp__mock-erp__get_control_population"],
    "deny": ["Read(./.env)", "Bash(rm *)"]
  }
}
9 · Tool과 Skill

Tool은 실행하고, Skill은 절차를 알려 준다

교재: AI-07 · Tool과 Skill 이해하기, 02 · monthly-close-brief Skill 실습

Tool

실제 작업이 일어나는 기능

파일 읽기, 명령 실행, 브라우저 열기, 게시처럼 호출하면 실제로 무언가 일어나고 결과가 AI에게 돌아옵니다. 전표 검토에서는 규정과 증빙 파일을 읽는 일입니다.

Skill

일하는 순서와 기준을 적은 문서 묶음

SKILL.md와 참고 파일입니다. 스스로 실행하지 않고, 언제 무엇을 어떤 기준으로 할지 알려 줍니다. 예: 규정 먼저 읽기 → 증빙 모두 대조 → 전표별 판정.

AI가 잘하는 일과 어려워하는 일

교재: AI-01

맡기기 좋은 일
  • 요약: 긴 문서의 결정·할 일 추리기 (원문과 대조)
  • 분류: 정한 기준·예시로 사례 구분 (경계 사례는 담당자)
  • 초안: 메일, 보고서, 코드 첫 버전
  • 형식 변환: 메모를 양식으로, 독자별로 바꾸기
  • 비교·추출: 원문 위치와 함께 요구하면 검증이 쉬움
조심할 일
  • 최신 정보: 날짜와 출처 확인
  • 숨은 업무 맥락: 문서에 없는 관행·예외 승인은 모름
  • 정확한 수치: 계산·집계·대사는 도구와 원본으로 재확인
  • 드물거나 모호한 사례: 오류 가능성 증가
  • 책임이 따르는 판단: 비용, 인사, 규제, 외부 발송은 담당자 승인

이 업무를 AI에게 맡겨도 될까: 네 가지 질문

  1. 입력 자료와 완료 기준이 분명한가?
  2. 결과를 원본·규칙·계산으로 확인할 수 있는가?
  3. 잘못된 결과를 적용 전에 발견하고 되돌릴 수 있는가?
  4. 개인정보, 금전, 권한, 대외 발송, 규제 판단이 포함되는가?

1–3이 분명하면 AI 보조를 검토하고, 4에 해당하면 담당자의 사전 승인과 최종 검토 지점부터 정합니다. 오늘의 전표 검토와 예산 보고는 1–3을 만족하고, 결재와 회의 결정은 담당자가 합니다.
